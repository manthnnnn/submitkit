## Dashboard Features

- **1-Click Test Scenarios** — Load preset expense events instantly
- **KPI Cards** — Total spend, approved budget, flagged count, compliance rate
- **Department Budget Envelopes** — Visual burn-rate progress bars per department
- **Expense Ledger** — Full list with approve/flag actions
- **OCR Receipt Inspector** — Simulated laser scanner animation with item extraction
- **Policy Engine** — Auto-flags weekend spends, >₹2,500 transactions, dining >₹500
- **Export** — Download expense report as CSV

## Tech Stack

- **Framework:** Next.js 16 (React 19, TypeScript)
- **Styling:** Pure CSS custom design system with CSS variables
- **Data:** Hardcoded simulation — no database or external API
- **Policy Engine:** Pure TypeScript rule evaluation
