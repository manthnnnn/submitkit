## PART 2: TOP 20 VIVA QUESTIONS & MODEL ANSWERS

1. **Q: What is the main objective of your project?**
   - **A:** The primary objective is to solve workflow fragmentation by implementing Healthcare Ehr Portal using Next.js 14, TypeScript, Tailwind CSS.

2. **Q: What SDLC model did you follow?**
   - **A:** We followed the Agile Scrum model in 2-week iterations, allowing continuous verification and iterative improvements.

3. **Q: Why did you choose Next.js 14?**
   - **A:** It offers exceptional performance, non-blocking asynchronous I/O, type safety, and rich developer tooling.

4. **Q: How did you test your project?**
   - **A:** Through unit testing, API endpoint integration testing, and cross-browser user acceptance testing.

5. **Q: How is security handled in your system?**
   - **A:** Through parameterized queries preventing SQL injection, strict input sanitization against XSS, and secure session management.

6. **Q: What is the database schema design?**
   - **A:** The database is normalized to 3NF to avoid data anomalies and maintain high referential integrity.

7. **Q: How does the system handle high traffic?**
   - **A:** Database indexing, connection pooling, and client-side caching ensure optimal throughput under load.

8. **Q: What was the most challenging part of development?**
   - **A:** Ensuring synchronous UI reactivity while maintaining transactional integrity across concurrent operations.

9. **Q: What is the future scope of this project?**
   - **A:** Adding mobile responsive notifications, distributed cloud clustering, and automated predictive analytics.

10. **Q: Can this be deployed in a production environment?**
    - **A:** Yes, the project is structured with Docker-compatible deployment scripts and production environment configurations.
