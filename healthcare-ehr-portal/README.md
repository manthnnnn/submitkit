## Tech Stack

- **Framework:** Next.js 16 (React 19, TypeScript)
- **Charts:** Recharts
- **Date Handling:** date-fns
- **Styling:** Tailwind CSS v4
- **Data:** All patient/drug data hardcoded — no database or external API required
