About the XGBoost + SHAP Model

This model is trained on the Ames Housing Dataset — a benchmark dataset with 2,930 house records and 79 features collected from Ames, Iowa. XGBoost achieves an R² score of 89% on the test set.

SHAP (SHapley Additive exPlanations) is used to explain each prediction — it assigns each feature an importance value for a particular prediction, telling you exactly why the model priced the house the way it did.
