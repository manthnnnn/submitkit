About the Phishing Detection Model

This system uses feature engineering to evaluate URLs based on patterns commonly found in phishing campaigns, such as high domain entropy, IP address obfuscation, and suspicious keywords.

It implements 15 distinct heuristic rules modeled after the PhiUSIIL Phishing URL Dataset features, which are then passed to a Random Forest Classifier for a final probability score.
