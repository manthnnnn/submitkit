About Isolation Forest

Unlike typical machine learning algorithms that profile normal behavior, an Isolation Forest explicitly isolates anomalies. Because fraud patterns are rare and different, they require fewer splits in a random decision tree to be completely isolated.

By building an ensemble of trees, the model assigns an anomaly score based on how quickly a data point was isolated. A shorter average path length across all trees means the transaction is highly suspicious.
