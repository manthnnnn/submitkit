About the PPO Trading Agent

Algorithm: Proximal Policy Optimization (PPO) is a Deep Reinforcement Learning algorithm developed by OpenAI. It trains an agent to maximize cumulative reward through interaction with an environment.

Environment: The stock market is simulated using Geometric Brownian Motion (GBM), a stochastic process that models real-world price dynamics including volatility and drift.

State Space: The agent observes [current price, portfolio balance, shares held, RSI-14, momentum]. Action space is {BUY=0, HOLD=1, SELL=2}.

RSI Strategy: The agent uses a momentum + RSI combined policy — buying when RSI < 30 (oversold) and selling when RSI > 70 (overbought).

Tech Stack: Python · FastAPI · stable-baselines3 · PyTorch · Gymnasium · yfinance · Chart.js
